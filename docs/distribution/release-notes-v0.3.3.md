# OneTool v0.3.3

这次更新重点加入基于 ScreenPipe 的“记忆日报”，把本地屏幕记忆采集、时间线理解和日报草稿生成接入 OneTool，同时合入故障修复向导、PDF 工具空间和官网交接页优化。

## 主要更新

- 新增记忆日报：接入 ScreenPipe 本地 API，读取 Accessibility / OCR 记录，生成清晰的竖向今日时间线。
- 新增 ScreenPipe 管理面板：支持 CLI 检测、安装/更新、Token 获取、API 地址配置、运行状态识别、启动/停止和日志查看。
- 新增时间线理解层：按时间段聚合一天工作，进行重复内容压缩、隐私过滤、应用/主题识别，并默认尝试调用已配置的大模型优化事件描述。
- 新增日报草稿：支持“日常日记”和“专业分析”两种简报口吻，保留工作流和博客草稿入口为后续功能占位。
- 新增自动总结设置：可配置每天自动生成工作总结的时间，为正式版的持久化日报管理做好入口。
- 新增日报持久化：支持保存、打开、删除历史日报草稿。

## 其他更新

- 新增疑难修复向导：提供组策略安装/打开和 Windows 打印机共享连接修复流程。
- 新增 PDF 工具空间：补齐 PDF 与图片互转、合并、拆分、页码处理等本地处理入口。
- 优化代理医生：保留代理环境变量大小写，避免 Windows 环境键名被错误覆盖。
- 优化官网首页和接收端交接文案，补充分发接收流程说明。
- 优化文件投放悬浮球图标与状态外观，保留更完整的 CPU / MEM 状态环和停靠交互。

## 升级提醒

- 记忆日报依赖本机 ScreenPipe 采集服务；OneTool 会协助安装和管理，但采集授权、Token 和隐私范围仍由用户确认。
- 大模型分析会尽量使用更多非敏感上下文提升时间线质量；密码、支付、登录等敏感窗口和关键词仍会被过滤。
- 当前 Windows 构建尚未代码签名，首次运行可能出现 SmartScreen 或“未知发布者”提示。
- 安装版支持应用内更新；便携版不支持应用内自动更新。
