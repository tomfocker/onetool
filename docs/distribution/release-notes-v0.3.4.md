# OneTool v0.3.4

这次更新重点完善图片处理和屏幕录制两个高频工具，同时把本次界面优化沉淀为统一规范，并修正仪表盘、侧栏的工具图标映射。

## 主要更新

- 图片处理新增自定义宽高，支持按比例裁切后保持目标宽高比，适合头像、封面、证件照等固定尺寸场景。
- 图片处理新增目标体积压缩，可在常见格式下尽量压到指定大小，减少反复导出和手动试错。
- 图片处理新增 ICO 输出纠偏，提升图标文件生成后的显示稳定性。
- 图片批量下载改为打包下载，并保留源文件命名，避免浏览器逐个弹窗和手动改名。
- 屏幕录制新增录制完成任务入口，可查看已完成文件并快速打开文件或所在文件夹。
- 屏幕录制界面重新整理为更清晰的选择、输出和主操作区域，减少重复说明和分散按钮。

## 体验优化

- 新增工具页 UI 规范文档，统一后续工具页面的信息层级、按钮样式、控件排布和状态展示。
- 补全仪表盘和侧栏图标映射，开发环境、空间分析、下载整理等入口不再回退到默认图标。
- 补全工具入口视觉映射测试，后续新增工具时能更早发现图标或渐变配置遗漏。

## 升级提醒

- 当前 Windows 构建尚未代码签名，首次运行可能出现 SmartScreen 或“未知发布者”提示。
- 安装版支持应用内更新；便携版不支持应用内自动更新。
- 新版发布由 GitHub Actions 直接生成正式 Release，安装包、便携版和更新元数据以发布页产物为准。
