# OneTool v0.3.5

这次更新是一个小版本修复，重点修正空间分析在 NTFS 极速扫描下对大体积虚拟磁盘文件的容量统计偏差，同时优化应用内更新失败时的提示文案。

## 主要修复

- 修正空间分析容量偏小的问题：当 NTFS 文件记录同时包含 `$DATA` 和 `$FILE_NAME` 大小信息时，优先采用更可信的较大值，避免 VHDX、VMDK 等大型虚拟磁盘文件被按部分数据段计入。
- 增加原生扫描器回归测试，覆盖复杂 NTFS 文件记录下 `$DATA` 尺寸偏小、真实大小保存在 `$FILE_NAME` 中的场景。
- 保持极速扫描发布流程不变：正式 Windows 包会在 Release 工作流中重新编译并打包最新 `ntfs-fast-scan.exe`。

## 体验优化

- 优化应用内更新检查的错误提示：GitHub 更新源网络波动、连接中断等场景会显示更简洁的“网络连接不稳定，请稍后重试”。
- 区分更新源解析失败与普通更新失败，减少用户看到底层错误堆栈或 XML 内容的概率。

## 升级提醒

- 空间分析重新扫描后，NTFS 极速模式的扫描大小会更接近 Windows 实际已用空间；极少量差异仍可能来自系统保留区、权限受限项、卷影副本或文件系统元数据。
- 当前 Windows 构建尚未代码签名，首次运行可能出现 SmartScreen 或“未知发布者”提示。
- 安装版支持应用内更新；便携版不支持应用内自动更新。

- 本地类型检查与生产构建：通过。
- Windows 安装包与便携版以 GitHub Actions Release 工作流产物为准。
