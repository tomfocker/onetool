# OneTool v0.3.6

这次更新继续修正空间分析的容量统计问题，并补上空间分布统计里更顺手的目录打开入口。

## 主要修复

- 进一步修正 NTFS 极速扫描容量偏小的问题：当大型 VHDX、VMDK 等文件使用 `$ATTRIBUTE_LIST` 扩展记录时，扫描器现在会对这类记录使用 Windows 文件元数据兜底，避免文件被计为 0 或只计入部分大小。
- 修正 D 盘等大容量分区扫描时，虚拟机磁盘、WSL2 `ext4.vhdx` 一类大文件可能没有被完整计入总量的问题。
- 增加原生扫描器回归测试，覆盖 `$ATTRIBUTE_LIST` 记录需要回退到系统元数据读取真实大小的场景。

## 体验优化

- 空间分布统计中的目录条目支持右键直接在资源管理器打开对应目录。
- 保持左键用于聚焦下钻、右键用于打开目录，避免用户在“看占用”和“进文件夹处理”之间来回切换。

## 升级提醒

- 升级后请对目标盘重新扫描一次，旧扫描结果不会自动重算。
- 空间分析的扫描大小会更接近 Windows 实际已用空间；少量差异仍可能来自系统保留区、卷影副本、权限受限项或文件系统元数据。
- 当前 Windows 构建尚未代码签名，首次运行可能出现 SmartScreen 或“未知发布者”提示。
- 安装版支持应用内更新；便携版不支持应用内自动更新。
