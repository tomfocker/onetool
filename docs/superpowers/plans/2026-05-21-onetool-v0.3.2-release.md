### Task 3: v0.3.2 Release Notes

**Files:**
- Create: `docs/distribution/release-notes-v0.3.2.md`

- [ ] **Step 1: Add release notes**

Create release notes with sections:

```markdown
# OneTool v0.3.2

这次更新重点完善代理医生，让 Windows 开发代理状态、目标代理可用性和单个软件走代理更容易判断和处理。

## 主要更新

- 新增代理医生状态灯总览：集中展示 Windows 系统代理、WinHTTP、命令行环境变量、Git、npm、当前进程和 Codex 进程状态。
- 新增代理目标测试：同时检查端口连通和标准代理请求结果，并展示延迟。
- 新增代理启动器：可以选择 `.exe` 或 `.com` 程序，通过当前目标代理启动新进程。
- 优化冲突诊断：当前值和目标代理不一致时，可直接测试当前值是否真的可用。
- 优化诊断布局：减少卡片数量，让状态、建议、当前配置和操作按钮更紧凑。

## 修复与优化

- 修复预览窗口加载旧 preload 时代理测试按钮报错的问题。
- 修复代理测试超时文案，把“端口可达但标准代理请求无响应”的场景解释清楚。
- 修复代理医生表格在较窄窗口下右侧操作按钮不可见的问题。
- 优化 `100.64.*` 等上游节点地址的提示，避免把可连端口误当成可直接配置的系统代理。
- 优化代理启动器路径校验，限制为可直接启动的 `.exe` 和 `.com` 程序。

## 升级提醒

- 代理启动器只影响由 OneTool 新启动的进程，并依赖目标软件读取 `HTTP_PROXY`、`HTTPS_PROXY` 或 `ALL_PROXY` 环境变量。
- 如果软件本身忽略代理环境变量，它不会被强制走代理；强制接管所有软件流量需要后续单独设计。
- 当前 Windows 构建尚未代码签名，首次运行可能出现 SmartScreen 或“未知发布者”提示。
- 安装版支持应用内更新；便携版不支持应用内自动更新。

## 验证状态

- 本地测试：待发布前更新。
- 本地类型检查：待发布前更新。
- 本地生产构建：待发布前更新。
- Windows 安装包 / 便携版构建：待发布前更新。
```
